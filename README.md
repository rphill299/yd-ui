# yd-ui

[[yt-dlp GitHub]](https://github.com/yt-dlp/yt-dlp)

See a problem? [Open an issue](https://github.com/rphill299/yd-ui/issues/new)

UI for yt-dlp, a robust command-line tool for downloading YouTube videos.

## Starting our Project
Go to our [latest release](https://github.com/rphill299/yd-ui/releases/tag/v1.2.1) and download the appropriate file for your operating system (.dmg for macOS, .exe for Windows).  Users will likely need to adjust their OS security settings to allow the app to run.

#### MacOS
- Download and open YD-UI.dmg
- Drag YD-UI.app into Applications folder
- Open Applications/YD-UI.app
- If MacOS blocks you from running the app, [follow these steps](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac)
- Sometimes requires multiple attempts

#### Windows
- Download and open YD-UI.exe
- If Microsoft Edge blocks you from downloading the app:
    - click ... (More actions)
    - click Keep
    - click ...
    - click Keep Anyway
- If Microsoft Defender blocks you from running the app:
    - click More Info
    - click Run Anyway
